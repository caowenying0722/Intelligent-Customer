# Prompt 输出安全边界

`prompts/main_prompt.txt` 只允许向用户发送简短的工具调用进度说明，不要求或输出隐藏推理、逐步分析、系统提示、策略细节和工具内部决策。这样可以保留用户体验需要的状态反馈，同时避免把 Agent 的内部控制逻辑当作回答内容暴露。

该约束由 `tests/test_prompt_contract.py` 锁定；`PromptSafetyPolicy` 仍在 Agent 和模型调用边界拒绝已知的指令覆盖/提示外泄模式。两者职责不同：提示词约束输出形态，安全策略在执行前拒绝高风险输入。

工具调用审计应继续使用结构化、脱敏事件，不得通过输出完整推理来替代审计记录。
